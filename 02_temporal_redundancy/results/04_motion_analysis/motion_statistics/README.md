# Motion Analysis Statistics

This directory contains the numerical outputs generated by:

`02_temporal_redundancy/04_motion_analysis.py`

The purpose of this analysis is to quantify temporal motion between frames and determine how motion magnitude and spatial coverage change as the temporal distance between frames increases.

---

## Analysis Overview

The motion analysis is the fourth stage of the temporal redundancy investigation.

The temporal analysis pipeline is structured as:

`01_temporal_structure.py`
→ `02_frame_similarity.py`
→ `03_temporal_difference.py`
→ `04_motion_analysis.py`
→ `05_temporal_correspondence.py`

Each stage answers a different question.

### Temporal Structure

Determines whether frames form continuous temporal sequences.

### Frame Similarity

Measures how visually similar frames remain across different temporal distances.

### Temporal Difference

Measures pixel-level visual change between frames.

### Motion Analysis

Measures the magnitude and spatial extent of motion between frames.

## Output Files

### `motion_summary.json`

Machine-readable summary of the complete motion analysis.

It contains the main configuration and aggregate results, including:

- dataset size,
- number of videos,
- number of shards,
- temporal distances,
- sampling configuration,
- successful comparisons,
- motion statistics,
- motion coverage statistics,
- analysis status.

This is the main compact summary file for programmatic use.

---

### `motion_summary.csv`

Aggregated motion statistics in tabular form.

The statistics are grouped according to temporal distance and dataset split.

Typical temporal distances are:

- 1 frame
- 2 frames
- 5 frames
- 10 frames

This file is intended for statistical inspection, comparison and downstream plotting.

---

### `video_motion_statistics.csv`

Video-level motion statistics.

Each row represents an individual video and summarizes its temporal motion characteristics.

This file can be used to investigate:

- videos with high motion,
- videos with low motion,
- variation of motion between videos,
- differences between temporal sequences,
- unusual or potentially interesting motion patterns.

It is particularly useful for identifying the heterogeneity of temporal dynamics across the dataset.

---

### `motion_errors.csv`

Contains failed or problematic motion comparisons.

For a successful run this file may be empty.

An empty file indicates that no motion-comparison failures were detected.

---

## Large Pair-Level Statistics

### `frame_pair_motion_statistics.csv`

This file contains detailed motion measurements for individual frame pairs.

It is the most granular output of the motion analysis and may contain a very large number of rows.

Because the dataset contains 500,507 frames, storing measurements for individual frame pairs produces a substantially larger CSV file.

The generated file is approximately 25 MB.

For this reason, it is intentionally excluded from Git version control.

The file remains available locally for detailed analysis and can be regenerated by running:

`02_temporal_redundancy/04_motion_analysis.py`

## Why Pair-Level Statistics Are Useful

Although the large pair-level CSV is not committed to GitHub, it is scientifically useful.

It contains measurements at the individual frame-pair level and can therefore support more detailed investigations such as:

- identifying unusually high-motion transitions,
- analyzing specific temporal distances,
- investigating individual videos,
- studying the distribution of motion magnitude,
- examining outlier frame pairs,
- performing additional statistical analysis.

The compact summary files provide the main published analysis, while the pair-level file is retained as a detailed local research artifact.

## Interpretation

Motion magnitude is expected to increase as temporal distance increases.

For example:

`frame(t) → frame(t+1)`

should generally contain less change than:

`frame(t) → frame(t+10)`

because a larger temporal separation allows more visual movement to occur.

This makes temporal distance an important variable for understanding whether information from neighboring frames can be reused during reconstruction.

---

## Research Significance

The motion analysis provides evidence about the temporal behavior of the dataset.

If neighboring frames contain significant but structured motion, temporal information may be useful for reconstruction.

However, increased motion can also make direct frame reuse more difficult.

This creates an important trade-off:

**Temporal proximity**

may provide high visual similarity but limited additional information.

**Larger temporal distance**

may provide more diverse visual information but require stronger correspondence or alignment.

Understanding this trade-off is important for the later reconstruction stages of the project.
